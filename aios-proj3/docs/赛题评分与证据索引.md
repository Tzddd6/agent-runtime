# 区域赛评分与交付证据索引

依据本项目保存的《2026年操作系统设计赛中西部与华南区域赛技术方案》（2026-10-10版本），第2.2节OS功能挑战赛道：项目/代码执行展示30%、文档20%、文档和代码注释规范20%、AI工具说明10%、演示视频20%。原文称这些为“权重的参考”；不是本队已经取得的分数。官网为https://os.xtnl.org.cn/，最终以最新通知和评审为准。

| 评分维度 | 材料与代码 | 当前缺口 |
|---|---|---|
| 执行展示30% | order_project、engineering_workflow、控制台Worker回执/ctx_ref、NUC验收 | 最终版本现场彩排与主场景视频 |
| 文档20% | 研发过程与问题解决、类似项目对比、验收报告 | 真实对照失败需持续披露，不能写全面领先 |
| 文档/注释20% | 核心模块头、源码接口与MIT/第三方说明、复现入口 | 队伍逐模块核对来源和人工审查记录 |
| AI说明10% | AI工具使用说明：名称/版本、环节、真实提示词 | 工具精确未知版本与本人贡献由团队补录 |
| 视频20% | 录屏与现场演示脚本、README视频入口 | 尚未录制及上传百度网盘；不能填假链接 |

## 提交条款对应

- 3.1.2(1)：完整代码/文档，功能、性能、创新分析及类似项目对比。
- 3.1.2(2)：过程、实现、注释、问题解决，以及AI工具三要素。
- 3.1.2(3)：演示视频上传百度网盘，分享链接放README。
- 3.2：使用第三方库、模块或借鉴源码时，在设计文档及源码头明确说明并遵守相应许可。

历史综合报告里的30/25/20/15/10为此前技术组织口径，不能替代上述区域赛评分。测试数量和覆盖率也不能线性换算为得分。
