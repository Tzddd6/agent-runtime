# 新版网页更新与 NUC 复验记录

日期 2026-11-23。源码目录 D:\gemini\aios。

## 本轮修复

模拟 cgroup 控制文件测试不再启动真实进程隔离器。显式传入的 Linux 委派路径仍由严格 Executor 校验，无效路径直接失败，禁止静默降级。增加反例回归测试。

## 本轮实测

- Windows 全量 54 项，53 通过，1 项 Linux 专项跳过。
- NUC openEuler 委派环境全量 54 项全部通过，无跳过，耗时 9.029 秒。
- NUC 原生 Worker CPU 实测 0.1996 核，节流 13 次。OOM kill 1 次，活动进程和资源占用归零，零残留资源组。
- Proj3 端到端脚本通过。故障注入分支失败及其下游跳过为预期行为，健康分支完成。该脚本自身输出 admission_only，其输出不能作为 cgroup 硬隔离证明；硬隔离证据来自上述原生 Worker 专项。
- Edge 固定模型夹具通过流式粗体、公式、代码块、表格、长回答、附件与 HTML 转义测试。未发付费模型请求。

## 网页更新结果

清理两个重复的本项目 18892 实例后，以新版源码唯一启动。保留原 native-web-data 数据目录。

- 对话 http://127.0.0.1:18892/
- 控制台 http://127.0.0.1:18892/console/
- /api/status、/api/chat/status、/api/model-profiles 均 HTTP 200。
- 在该运行实例真实提交文档任务，Worker 成功，浏览器无报错。

本轮更新的是本机原生网页，未替换 mc.tzddd.cn 公网旧站。

## 验收边界

本轮解决了剩余 NUC 回归错误并验证新版网页接入，不代表历史所有功能都完成迁移。真实桌面鼠标键盘控制仍需要原生执行端接入，现有 LiteCUA 状态模拟不能当作真实桌面能力。附件解析尚未全部纳入 Worker 隔离。网页生产认证、生产部署和真实模型费用对照未在本轮执行。
