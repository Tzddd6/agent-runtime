# 原生控制台接入验收记录

在项目目录运行 `python -m runtime.web --port 18892`，访问：
- 对话与任务工作台：`http://127.0.0.1:18892/`
- 内核与 Proj3 监控台：`http://127.0.0.1:18892/console/`

## 已接通能力
1. **统一原生内核执行**：全部 10 类 Preset（`dynamic`、`document`、`kernel`、`resources`、`agents`、`ipc`、`litecua`、`llm`、`team`、`engineering`）均经原生 `AIOSKernelRuntime`、`WorkflowEngine` 与 `Cerebrum` 协议执行，并支持独立分支并发、资源等待、重试、故障分支隔离与原子落盘（重启自动将未结束任务标为 `interrupted`，不自动重提）。
2. **对话、流式与模型持钥**：支持 Chat Completions / Responses 双协议真实 SSE 流式对话（`/api/chat/turns`）、纯内存多供应商模型配置与切换（`/api/model-profiles/*`），密钥不落盘，并在对话期间加锁保护配置修改。
3. **附件上传与文档解析**：支持 `/api/attachments` 上传图片、DOCX、PDF 及归属校验；PDF 优先使用 `pdftotext`，在受限环境或无外部二进制时自动回退至 `pymupdf`（限前 60 页、拒绝加密 PDF）。
4. **六篇论文生态全量接入**：
   - **A-Mem**：原生记忆录入（`/api/memory/save`）、双向建链演化与私密/共享/跨用户隔离；
   - **LSFS**：自然语言文件指令终端（`/api/aios/intent`）；
   - **LiteCUA**：虚拟桌面无障碍树观察、点击、输入、快捷键与快照回滚（`/api/aios/litecua` + `litecua` 场景），全链路经原生 `ToolQuery` 系统调用审计；
   - **AgentHub**：内置 4 个带 Manifest 权限与资源配额的系统 Agent App 清单展示；
   - **知识库**：SQLite FTS5 双语检索、录入与移除（`/api/knowledge`、`/api/knowledge/search`、`/api/knowledge/save`、`/api/knowledge/remove`）。
5. **远程内核协议与安全边界**：支持 `/core/status`、`/core/syscalls`、`POST /query`、宿主机/cgroup 遥测（`machine`）以及 Agent 生命周期控制（`pause`/`resume`/`terminate` 与在途排空）。所有本地页面严格校验 `127.0.0.1` 回环、`Host`/`Origin`、CSRF、请求体上限并转义展示内容。
