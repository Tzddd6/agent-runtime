模型与 API ↗

会话、附件、知识库和记忆按登录账号分区。同一账号的成员仍共享该分区；导入资料前请移除敏感信息。

记忆按当前登录用户隔离。私有记忆仅供 assistant，团队协作需显式选择“同用户 Agent 共享”。请勿保存密码或密钥。

每次模型请求最多注入 8 KiB，包含格式开销。

移除后不再注入后续请求，已经发送的内容无法撤回。旧团队资料归原登录账号保留，其他登录账号使用独立分区。

在当前用户分区保存资料，跨对话检索。命中片段会连同版本和行号提供给模型，引用可在回答下方核对。
