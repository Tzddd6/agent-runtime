# v0.19：专用电脑 Bot、工具恢复与长回答

本轮以 openEuler / NUC 的独立实验桌面为目标，不连接个人桌面。浏览器有真实虚拟显示、DOM 观察、输入、点击、有限按键、滚动、公开 HTTPS 导航和截图；已有受控文件与命令工具继续独立使用。它尚不支持任意原生应用、视频理解、Canvas 坐标操作、登录会话跨请求保存或绕过验证码。

## 实现关系

聊天 → 本地意图识别或模型路由 → Agent 控制块 / Task / Attempt → cgroup 准入 → 电脑执行端 → bubblewrap 内 Chromium + Xvfb。每个模型动作仍通过 Runtime 临时模型网关及累计预算，供应商密钥不交给浏览器或工具进程。每次会话结束回收其进程树；网页显示真实步骤与校验 SHA 的截图。

浏览器无宿主网络，通过宿主受控桥接读取公开 HTTPS GET；DNS 全局地址检查与固定连接地址防止内网访问和 DNS 重绑定。拒绝 POST、WebSocket、外部文件路径、密码/支付/删除/发布动作，不转发用户凭据或 Cookie。最多 12 步，100 次资源读取、20 MiB 总下载；这些限制不等于对恶意多租户的完整安全证明。

## 部署依赖与验证

核心要求 Python 3.11+。电脑可选依赖是 bubblewrap、Xvfb、Chromium 所需 NSS/ALSA/GBM 库与中文字体。NUC 使用发行版依赖、Playwright 1.65.2 与官方 Chrome 157.0.8103.78；不把浏览器二进制加入项目包。Playwright 自带浏览器下载在现场出现网络超时，保留该失败；NUC 最终使用从官方渠道取得的用户缓存浏览器。

```bash
python3 -m venv ~/.local/share/agentrt-browser-venv
~/.local/share/agentrt-browser-venv/bin/pip install playwright==1.65.2
~/.local/share/agentrt-browser-venv/bin/python -m playwright install chromium
# 安装上述发行版组件后，在足够 TasksMax 的受限服务中执行：
~/.local/share/agentrt-browser-venv/bin/python tools/validate_computer.py
```

验证工具只在真实点击成功、宿主 home/loopback 隔离检查成功以及 Chromium 报告沙箱开启后写入准备标记。安装失败不得关闭 Chromium 沙箱降级。电脑任务准入上限 1 核 / 1 GiB / 224 pids，网页总服务仍有 2 核 / 2 GiB / 256 tasks 上限，普通任务保留原上限。现场 128 tasks 不足以启动浏览器，不能照搬到电脑任务。

## 本轮修复

- 明确读取网址或裸域名时直接使用实际 web.fetch，成功后才做一次总结；401 如实返回，不带凭据尝试登录。兼容固定协议别名 web.read，其他不存在工具仍拒绝。
- 工具的 SyntaxError/参数错误作为结构化观察返回，最多按原有三轮边界修正；网络超时不重放模型请求。无效计划最多一次格式修复，不扩大权限。
- 普通讲解由一次完整回答处理，4096 输出额度，达到确认的长度上限时最多一次续写；大型 SVG 最多三次续写。每个新请求独立准入、记录 token，不承诺未知状态请求重发安全。
- 生成 SVG 可修复最多四处重复属性引号；其他 XML 语法错误最多两次局部模型补丁，只可替换当前错误窗口内的唯一原片段。之后对整文件重新做安全结构校验。仍失败时明确显示未交付，不能把工具进程正常退出当作任务完成。
- JSON 提示区分金额/数量数值与编号字符串；用户显式类型约束优先。

## 真实结果与限制

原冻结版本 5926336 的 10 场景 × 2 组 × 2 次重复，共 40 例、51 次真实调用。对照是具有相同工具与验证器的串行直接循环，而非只能猜测答案的裸模型。统一 2 核 / 1 GiB / 256 tasks，总机会和单次输出上限一致，交错运行；模型采样、缓存和公网状态未固定。

| 指标 | 直接工具循环 | Runtime |
|---|---:|---:|
| 独立通过 | 20/20 | 18/20 |
| 耗时中位数 | 2.138s | 2.546s |
| 输入 + 输出 token | 28,563 | 29,446 |
| 模型调用 | 25 | 26 |

Runtime 此批约慢 19.1%、总 token 多 3.1%，尚未证明整体优势。两项 Runtime 失败是 PDF/Word 金额 JSON 返回字符串，原题未明确类型，保留严格判定和题意歧义。首次金额工程外部判分器漏建目录，已对同一产物零调用复核，原评分与哈希保留；未改原有项目测试。后续显式类型提示的 4 次独立补测均通过，但不能替换主实验成绩。

现场还单独验证了 B 站公开首页与真实浏览器操作、裸域名读取、金额工程修复、三格式上传及伪装文件拒绝。B 站测试仅证明观察到实际页面与导航，不能冒充观看完视频。

新增长回答实测“详细介绍拉普拉斯变换”：1 次调用，8.308 秒，2949 字，109 输入 / 1584 输出 token，正常结束。覆盖定义、性质、收敛域、反变换与应用；并非对数学表述逐句无误的保证。

私人复杂 SVG 先前截断和语法失败均保留。后续 4 次生成/续写得到 41840 字节正文；复用同一输出，用 1 次局部修复、328 token 保存 41860 字节、476 元素的安全 SVG。其数量、数学与审美约束未全部验收。私人原题、模型全文、数据库和凭据不随公开源码交付。
