# 框架评测口径

HumanEval前五题仅是公开数据接入与隔离判分试跑，不是框架优势证明。固定提交b9453e8f1865df0a0057a1383767caa400acfbcf；直调4/5、Runtime5/5；中位耗时1.111s与1.305s，总token1066与1153。每题只有一次且供应商采样未固定，完成率差异不可归因于框架。

框架主指标应在相同模型返回和工具轨迹下测量：控制面CPU与RSS、工作流总延迟及排队时间、进程启动次数、上下文传输字节与RPC、取消到回收的延迟、故障隔离成功率、残留进程/cgroup、预算与权限违规次数。模型推理时间和框架时间分开记录。

真实端到端评测必须同模型、同初始信息、同工具权限、同资源总预算、同调用机会与输出额度、同原始判分器，并交错重复。任何缓存、上下文压缩或少调用策略都必须通过独立质量门槛；不能删测试、看隐藏答案或挑选有利样本来达成“数值超越”。

GitHub参考：BrowserGym用于浏览器工具协议与环境适配；tau2-bench用于工具状态和策略遵守；HumanEval用于轻量代码链路。未适配的官方完整基准不能列为已通过。参考仓库分别是 https://github.com/ServiceNow/BrowserGym 、https://github.com/sierra-research/tau2-bench 、https://github.com/openai/human-eval 。
