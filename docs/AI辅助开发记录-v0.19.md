# v0.19 AI辅助开发记录

本轮由 AI 辅助编写实验浏览器控制端、协议容错、有限长输出续写、SVG 局部语法修复、测试与文档；队员需要审查源码并理解机制，按比赛要求记录自身实现和验证贡献。

人工需求是 NUC 专用实验桌面，不控制个人电脑。关键决策是保持 Chromium 沙箱与公开 GET 限制、统一 Runtime 模型/资源准入、真实工具结果为证据，以及对未知计费状态不自动重试。

测试在 NUC 实机执行，包括真实浏览器点击输入、文档解析、金额/配置/日志工程、OOM/PIDs/后代回收，以及 40 例具有同等工具的真实对照。原判分脚本漏建外部检查目录、root 验收解析器失败、长输出截断、XML 语法失败都保留记录，没有修改原工程判分器或替换原失败成绩。

此阶段仍未达成通用性能优势或全场景无错误保证。复杂图形的完整语义和任意原生桌面操作没有完成验收。公开证据是经过筛选的汇总，不含用户私人原题、聊天数据库或密钥。
