## 本轮新增

- context_control.py：文本视图预算、检索、分页、来源与冲突。
- contracts.py：非空语义主张和 JSON 对象契约，发布前检查。
- runtime/ipc/worker：依赖授权与显式转授、批量取视图、视图统计。
- 网页常规设置和监控：上下文模式与真实数值；能力库 22 工具、9 Skill。
- 已验证补丁以精确源码与完整 SHA 生成可下载产物，不把另写源码当作已测版本。
- doctor、免费共享示例、脱敏实验与独立完整交付包。

## 验收口径

常规 230 项发现，222 通过，8 项环境跳过。另 16 项严格 cgroup 检查通过。报告在 validation/context-2026-11-16/regression.json。真实上下文两种模式各 3 次关键字段均正确，模型输入合计减少 85.8%，只支持该合成负载下的结论。

初始三模型语义协作出现空事实失败。增加可声明结果契约后的独立三次模型调用验收通过，仍保留原失败。网页另做一次真实调用验证模式与统计传递。更早 v0.15 直接 API 对照没有证明整体优势，不应把新专项结果混入旧对照并宣称总体胜出。

比赛演示建议先运行免费 DAG 与冲突通信，再展示实际 cgroup 限制、三类工程之一，以及带有原始失败的真实模型实验。性能、成功率、token 与本机资源分别报告，避免单一“更快”指标遮盖质量下降。团队须理解、修改和复现实验，并按当前章程如实说明 AI 辅助与成员贡献。
