# v0.4 AI 辅助开发记录

按用户明确要求，本次由主智能体与三个子智能体并行开发：资源管理器界面、论文调度机制、论文上下文机制。主智能体完成采样、限轮评审、集成、模型总期限监督和 NUC 部署。随后三个子智能体分别审查执行面、调度面和控制面，提供最小复现，再按文件边界修复并交叉验证。

已阅读 AIOS、AutoGen 原文和 Linux 官方调度文档；来源及复现/借鉴边界写入三份“论文机制”说明。本项目不将 LRU-K、对话编程或现有操作系统调度概念表述为原创，也未完整复现论文系统。公平排空是本项目结合现有目标的组合实现。

架构审查包括并修复：清理短路、启动管道阻塞、供应商滴流超时、任务准备异常级联、监控阻塞、ACK 碰撞、清理未知仍接新任务、配置竞态、断网旧指标和缺失异常日志。详细证据与保留边界见“架构审查-2026-11-11.md”。

模型相关自动测试使用本地模拟供应商；没有代用户调用真实付费 API。供应商密钥不进入 Git、源码包或测试报告。控制台后端重启会清除已配置的内存密钥，已提前告知用户。团队仍需亲自审查、修改、解释核心实现，并按赛事要求记录实际贡献。
