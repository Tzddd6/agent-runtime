# 聊天 Markdown 显示修复（2026-11-15）

旧版只识别三反引号代码块，其余回答作为一整段纯文本展示，因此 `###`、`**` 和列表标记直接出现在对话中。现改为 `static/markdown.js` 构造原生 DOM，`chat.js` 调用渲染器，`chat.css` 负责排版。旧会话刷新后直接获得新排版，无需重新调用模型或改写保存的回答。

支持标题、加粗、斜体、删除线、段落、单行换行、有序/无序及嵌套列表、引用、分隔线、简单表格、行内代码和围栏代码。代码块保留缩进、tab 与内部 Markdown 字面量，复制按钮读取原始代码文本。加粗容忍模型在关闭标记前保留空格的常见写法。

这是一套有界 Markdown 子集，不宣称完整 CommonMark 兼容。原始 HTML 始终显示为文本，远程图片不自动加载。仅允许显式 http/https 链接，使用新窗口与 `noopener noreferrer`。渲染器不用 `innerHTML`，不执行模型输出。

验证：`node tools/test_markdown.cjs` 七组检查通过，覆盖中文标题与加粗、嵌套列表、代码保真、转义、表格、危险输入和未闭合语法。NUC 的 `test_chat test_agent_web test_repair_web` 共 14 项检查通过。浏览器只读打开用户现有回答，确认标题、加粗与列表实际生效，没有新增模型调用。验证摘要不保存用户提示词或回答正文。
