# 用户需求与验收清单

本清单用于保留本次连续提出的需求。日期2026-11-15，开发版v0.15（保留v0.14性能实验）。

| 需求 | 已实现与证据 | 边界 |
|---|---|---|
| 取消固定选项、自动路由 | 聊天入口统一；模型生成受校验任务图 | 每轮最多12项、最多3轮，不保证任何任务均成功 |
| Agent一等对象 | 继续使用ACB、生命周期、聚合cgroup与模型账本 | 生命周期限于工作流，不是Linux内核新增对象 |
| 大任务容量 | 工作流128调用/262144输出额度，单次4096；100轮会话 | 每次运行单独核算，输入另计，不是金额上限 |
| 深度思考 | 真实供应商thinking/high参数；独立与网页使用量确认 | 保留截止时间，不展示或落盘原始思考 |
| 常用插件和Skill | 20个工具、9份本地受检Skill，按需加载 | 不自动安装外部代码，不授予Skill额外权限 |
| 联网浏览 | 公网HTTPS文本、证书验证、每跳公网IP校验 | 无JavaScript执行，禁止内网和凭据URL |
| 命令执行 | 已安装发行版bubblewrap，命名空间+cgroup隔离 | 主机home不可见，命令网络关闭 |
| 文件修改与产物 | 项目读写、按字节复制、哈希替换、互斥与下载 | 限于会话工作目录，不能读写宿主其他路径 |
| 自身观察后迭代 | 工具证据跨轮传递，基于失败修改计划并复验 | 不是在线自改Runtime源码，也不自动重放付费POST |
| 系统配置权限 | 真实调整当前Runtime工作流并发与调度策略 | 不能扩大资源总额或修改宿主认证/其他服务 |
| 图片与文件 | PNG/JPEG与UTF-8文本上传，真实视觉模型验收 | 有大小/像素/格式限制，不支持任意文件格式 |
| 长期知识库 | SQLite FTS5中英文检索、跨对话资料、版本与行号引用、历史快照；两次真实模型引用通过 | 关键词检索，暂不支持PDF/Word、向量检索；团队共享 |
| 白色工作台 | 浅色聊天、分类设置、能力搜索、资料管理、独立真实监控 | 参考用户截图布局，只有实际支持的设置 |
| 数据库 | SQLite WAL附件元数据、数值观测、工具审计 | 会话正文仍为JSON；不是多租户数据库平台 |
| 节省资源与token并提高质量 | 固定同预算3轮交错；耗时、CPU、token及见证/覆盖检查 | 小样本；未证明实际内存稳定下降或所有任务同比改善 |
| 安全与无bug诉求 | 212项发现、204通过、8环境跳过；另12严格检查通过 | 测试不能保证绝对无漏洞；共享内核及团队登录仍有限制 |
| 网页实际互动 | 真正上传、运行、停止、看步骤与下载；浏览器检查 | 非逐token流式输出 |
| 项目介绍PPT直接到工作区 | 15页PPT，含架构、机制、资源数据、功能与边界 | 以本地交付文件为准，未自动发QQ |
| GitHub交付 | 源码、使用指南、脱敏实测与失败记录推送功能分支 | 不覆盖main，不把私有密钥或运行数据推送仓库 |

四类真实功能验收：原生思考；图文附件；源码修复且测试文件字节不变、独立检查通过；公网读取且Runtime配置已实际应用。开发期间3次修复失败与1次控制异常保留在原始报告，没有当成成功。

实测修复包括：后续规划缺少完整协议、跨轮证据遗忘、同秒同大小Python修改复用旧pyc、降低并发导致负槽数。新增回归覆盖这些触发条件。控制异常只在核实无残留Attempt、无在途模型调用并归档原隔离记录后恢复，保护机制继续保留。

数据见 `validation/agent-2026-11-15/`；使用与权限详见《自动Agent与插件技能-v0.14》。
