NUC 实验目录：`/home/tzd/agent-runtime-real-experiments-20261111`。原版项目在 examples/engineering/，独立测试和补丁限制在 agent_runtime/engineering.py。数据在 reports/real、reports/real-fixed 与 reports/summary，首批失败没有删除。

无需 API 的代码复查（受限项目，不接受任意仓库）：

```bash
cd /home/tzd/agent-runtime-real-experiments-20261111
python3 -m unittest -v test_engineering test_collaboration_evidence test_real_analysis
python3 -m agent_runtime.engineering baseline --workspace reports/baseline-recheck
```

baseline 预期返回非零，因为原版有缺陷。真实模型补丁保存在 reports/real-fixed/project-r0-w1-fifo/model-patch.json，可用 engineering check --response 复查；执行任何外来补丁仍需使用限额的 systemd 服务，不应依赖 AST 白名单替代 OS 资源限制。

重新跑一轮在线实验会消耗额度，先在现有控制台保存密钥，然后：

```bash
sudo systemd-run --unit=agentrt-project-new-run --wait --pipe --collect \
  -p User=tzd -p Delegate=yes -p CPUQuota=100% -p MemoryMax=768M \
  -p TasksMax=128 -p RuntimeMaxSec=1200 \
  /usr/bin/python3 "$PWD/tools/run_real_console_experiments.py" \
  --output-dir "$PWD/reports/new-run" --repeats 1 --max-calls 40
```

工具仅调用现有控制台，不导出供应商密钥。每次 POST 只尝试一次，响应丢失不自动重提；已有调用检查点时拒绝同目录重复运行。连续两次管线错误停止后续付费调用。调用上限包括协作与限轮评审，不等于成功调用数，也不保证失败请求不会计费。
