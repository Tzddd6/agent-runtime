# 真实场景与实验的 AI 辅助记录

按用户要求，三个子智能体分别实现受限项目/验证器、统计汇总器、协作证据与缓存重放；主智能体负责整合、真实模型调用、故障诊断和 NUC 实测。夹具、独立用例和 AST 限制由 AI 辅助生成，不冒称来自生产项目或团队独立设计。

真实调用中发现供应商默认思考与短输出预算不兼容，空正文被旧实现接受；修复为显式关闭思考并拒绝空正文。初批失败诊断的用量与估算费用保留在交付数据中。为不超过已声明的 100 次调用上限，修复后在线对照仅各配置一次；缓存另做三次固定结果重放。未把重放伪称新推理，也未把 n=1 的耗时差异写成普遍性能优势。

供应商密钥始终由原控制台保管，未导出、未放入 Git 或报告。测试工具不继承供应商密钥；代码补丁只在固定 AST 子集、受信任检查器、墙钟截止和委派 cgroup 限额下执行，不构成任意 Python 的安全沙箱。团队仍需阅读、审查并亲自解释这些机制及实际贡献。
