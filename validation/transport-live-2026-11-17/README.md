## 45秒与格式流式诊断

旧45秒来自持钥父进程硬期限，原失败缺阶段，不能回溯断言网络具体位置。本轮原45秒基线的两个复杂格式请求均成功：响应头约8.358/9.256秒到达，终态约9.894/10.802秒；说明这两个样本接口开始响应前的等待占主要部分。协议没有复现固定格式解析错误。

新90秒策略下的复杂格式两次验证：一次10.883秒成功，一次29.734秒失败。失败已收到HTTP200和SSE响应头，非90秒截止；当时细分错误类别尚未记录，不能断言是中转错误事件还是缺终态。补充的单次分类诊断4.970秒成功。总计本轮5个格式探针4成功1失败，均保留，不声称完全解决该站的复杂流式稳定性。

成功探针覆盖加粗、公式、代码块、表格，累计text等于最终正文；只处理assistant/output_text，reasoning未公开但仍计入token。之后不再追加付费请求。
