本轮没有调用供应商模型，费用为零。原四轮航空成绩的冻结源代码与轨迹未改变，本目录不是新的榜单成绩。

## 恢复与安全

Runtime 与网页真实执行链已接入私有持久检查点。启动 Worker 前先保存执行意图，完成后保存确认结果、动态任务、上下文授权及模型额度。恢复不会重复已完成步骤，不清零模型预留和已记录用量。对结果不确定的模型调用、命令和写操作阻止自动重放。旧执行资源未确认回收时隔离新准入。

网页“结果与事件”显示检查点，已中断的安全演示支持显式恢复。复杂模型/工程操作仍需人工核对。本机同一 Unix 账号具有读取自身文件的能力，API 身份隔离不等于针对同账号恶意代码的密码学隔离。检查点最大16MiB，含私有任务内容，不公开原始文件。

Linux419项：418通过、1项Node环境跳过；该Node前端控制检查在Windows单独通过。启用真实浏览器及cgroup测试，无残留执行cgroup。真实SIGKILL用例确认：旧Worker仍存活时拒绝恢复，回收后续跑，已完成写入只发生一次。模型预算、动态Agent及调用计数均保留。

同50条历史模型回复、相同官方工具和判分器，正反顺序各跑一次。基线Ada18ba9平均66.4809秒，候选a2dd1b339346b2d79259a2b698cb195375329273平均59.7035秒，直接调用38.7935秒。固定请求、完整对话与奖励均一致，保留原39/50奖励。候选耗时减少10.19%，仍慢于直接调用，不是新的模型能力分。

该候选回放关闭可选检查点。之后的发布修复集中在恢复分支（补齐动态Agent账本、用量计数与资源隔离）及不完整HTTP头的关闭边界，另由完整回归和持久化实验验证。没有把不同冻结源码描述为同一轮实测。两次重复不构成普遍或统计显著的提速结论，协调CPU基本相同，不能声称CPU/整体内存或token全面下降。
